SUPERPROFE

Para empezar en Windows:
1. Descomprime el ZIP completo en una carpeta (no abras la aplicación desde dentro del ZIP).
2. Abre index.html con doble clic en Microsoft Edge o Google Chrome.
3. La aplicación funciona sin internet y guarda los cambios en ese navegador y ordenador.

COPIA DE SEGURIDAD
Pulsa «Copia de seguridad» y después «Guardar copia». Guarda el archivo descargado en un lugar seguro. Para recuperarlo, abre la aplicación, selecciona «Abrir copia» y elige el archivo. La restauración reemplaza los datos actuales.

IMPORTANTE: si borras los datos del navegador, cambias de navegador, mueves la carpeta o cambias de ordenador, los datos guardados podrían dejar de estar disponibles. Conserva copias de seguridad. El temporizador no continúa en segundo plano si se cierra la aplicación.

Si Windows no muestra las extensiones, busca el archivo llamado index con el icono de tu navegador. Mantén todos los archivos y la carpeta assets juntos.
